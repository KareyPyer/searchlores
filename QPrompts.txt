## 🎨 POUR ALLER PLUS LOIN

### Ajouter plus de plugins built-in

Le repo a 6 plugins built-in. Dans la GUI, assure-toi de les avoir tous dans le sélecteur :

```python
# searchlores/gui/widgets/plugin_selector.py
AVAILABLE_PLUGINS = {
    "Authority Detector": AuthorityDetector,
    "Assumption Extractor": AssumptionExtractor,
    "Contradiction Finder": ContradictionFinder,
    "Omission Detector": OmissionDetector,
    "Narrative Archeologist": NarrativeArcheologist,
    "Cognitive Genealogist": CognitiveGenealogist,
    "Lisp Exporter": LispExporter,  # ← Ajouté
}
```

### Créer tes propres Lores

Dans `lores_custom/`, crée par exemple `latin_politics.lore` pour investiguer spécifiquement les prompts qui invoquent le latin comme autorité politique :

```yaml
version: "1.0"
metadata:
  name: "latin_politics"
  author: "Toi"
  tags: ["latin", "politics", "authority", "tradition"]
  description: "Déconstruction de l'autorité latine dans le discours politique"

investigation:
  assumptions:
    - "Le latin est une langue neutre et intemporelle"
    - "La tradition romaine est un modèle universel"
    - "Les concepts politiques latins sont encore pertinents"
  
  myths:
    - "roman_wisdom": "Les Romains avaient raison sur la politique"
    - "latin_neutrality": "Le latin n'a pas d'idéologie"
  
  vectors:
    - "colonialism"
    - "class"
    - "language_power"
    - "historical_continuity"
  
  questions:
    - "Qui parle latin aujourd'hui, et pourquoi ?"
    - "Quelles voix sont exclues quand on invoque le latin ?"
    - "Quelle vision du pouvoir est présupposée ?"
  
  counter_questions:
    - "Et si le latin était lui-même un acte politique ?"
    - "Et si l'universalité romaine était un mythe colonial ?"
  
  forbidden_answers:
    - "C'est juste de la culture classique"
    - "Le latin appartient à tout le monde"
```
